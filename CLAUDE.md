When making new sections, don't look at previous animations, just tell the helpers the process, without looking at examples.  
When adding new anims to existing sections, looking is allowed.  
Also remember that the first line of an animation file is a code comment description of the animation.  
The second line is `// tags: a, b, c` (3-6 lowercase search tags, rules and starter list in docs/CONTRIBUTING.md) and the third is `// ---`, then any notes and the code.
