<h1 align="center">vibegif</h1>

<p align="center">public domain gallery of gifs and animated webp<br><a href="https://vibegif.direct-img.link">vibegif.direct-img.link</a></p>

Every anim is CC0, hotlink away.

```sh
npm i
npm run dev    # preview the gallery
npm run gen    # render new anims-src/ scripts into public/
npm run build  # site/ pages + public/ go to dist/
```

Want to add some? See [CONTRIBUTING.md](CONTRIBUTING.md).

Building a UI with an AI agent? Give it the [skill](../skills/vibegif/SKILL.md) and it finds and adds anims on its own.

Searching from code or the terminal? [Python](../packages/python) `pip install vibegif`, [JavaScript](../packages/npm) `npm i vibegif`, [Rust](../packages/rust) `cargo add vibegif`.
